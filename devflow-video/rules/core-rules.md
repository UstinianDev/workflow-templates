# 方法论核心规则（每次必用）

> 这是 /devflow-video 生成与自检节点的内核。词库/映射表/审美表/时间戳法在 `references/`，按需读，不默认进上下文。
> **诚实定位**：本节"核心理论"与"单段硬约束 ≤3 / 视觉词 ≤6"是**经验初值，非实测/引用结论**，作为保守起点执行；出片验证（SKILL 步骤 7，待建）后回修。不要把它们当硬科学规格对外担保。

## 一、核心理论（经验启发，非可证伪定律）
1. 条件生成：提示词收窄采样范围，不是穷举指令。
2. 主体决定注意力分配；改主体 = 整段跟着变。
3. 景别 = 空间维度的算力分配（经验类比，指导取舍用，非物理因果）。
4. 动作铁律：**模仿而非教学**——写"球落下弹起"，不写"9.8m/s²"。（本组最站得住的一条）
5. 场景 = 全局持续条件（空间/光照/材质/一致性）。
6. 约束竞争：约束越多越互相干扰，**不是越多越好**；单段硬约束初值 ≤3，其余留空（见顶部诚实定位）。
7. 主体一致性铁律：多镜头贯穿同一主体 → 走 **chaining**（上一镜尾帧 → 下一镜首帧参考图），不靠纯文本让模型每段自行保持一致。规范查 `references/chaining.md`。

## 二、填空法三句话（单镜头）
```
[景别] + [主体]
[动作]
[场景精细化描述]
末尾一行：[风格关键词]
```
多镜头：总主体贯穿 → 按时间线切段（0~3s / 3~6s…）→ 每段三句 → 末尾风格行。

## 四、四原则校验规则（自检节点直接可用）

| 原则 | 检查方式 |
|---|---|
| 具体性 | 抽象词命中黑名单（4.1）→ 改写为可见画面（拆法查 `references/aesthetic-params.md`） |
| 非矛盾 | 互斥词对共现检测（4.2） |
| 正面描述 | 扫描否定词 + 白名单（4.3） |
| 不过度指定 | 单段硬约束/视觉属性词超阈值删减（4.4） |

### 4.1 抽象词黑名单（命中即改写为可见画面）
```
破碎记忆 / 史诗感 / 孤独感 / 压抑 / 震撼 / 悲壮 / 苍凉 / 压迫感 / 窒息感
紧张 / 惊艳 / 唯美 / 高级感 / 电影感 / 大片感 / 仪式感
```
拆成具体参数查 `references/aesthetic-params.md`。

### 4.2 互斥词对（同主体同时段命中即删一或拆分）
静止+移动 · 碎片状+连续弧线 · 无风+飘动 · 特写+环境全景 · 第一人称+主角正面 · slow motion+快速
（张力手法例外：大远景+小尺度动作 可用于制造"威胁感/渺小感"，属有意留白非矛盾，但须在自检标注）

### 4.3 否定词扫描 + 白名单
扫描（整词/词组，勿用裸字触发）：`不要 别 避免 无<具体名词> 不出现 没有 no not without avoid`
白名单（合法，不改）：`无风 / 无烟 / 无尘 / 无配乐 / non-stop / 不断`
**注**：白名单是"无+名词"词组匹配，非裸字"无"；用户想保留的合法负面控制（如"无水印""无字幕"）不在白名单外被误放行，须逐词判断，不静默放过。
音频段例外：允许 "purely diegetic" 等 negative 描述（音频模型支持）；画面段按不支持处理（见 model-matrix 负面分层）。

### 4.4 不过度指定 · 阈值
- "段" = 一个时间戳块（如 0~3s）
- 硬约束（景别/视角/构图/运动）单段 >3 → 删到 ≤3，删减优先级：镜头运动 > 构图 > 视角 > 景别（景别不可删）
- 视觉属性词（颜色/材质/方位/光效各自去重）单段 >6 → 删减告警，保留最相关的 6 个

## 五、风格短语库（光线 + 色调，速查）
| 光效描述词 | 情绪 |
|---|---|
| 柔和金色晨光 | 温暖明亮 |
| 乌云冷暗光 | 孤独 |
| 雷电暗红紫映光 | 压迫 |
| 夕阳彩虹交织柔光 | 温暖释然 |

- 光线：high-key（明亮均匀/喜剧）、low-key（强对比深影/悬疑）、逆光光晕（分离主体背景）
- 色彩心理：绿=平衡自然、红=愤怒激情、蓝=悲伤疏离
- 风格锚定词：皮克斯 / 吉卜力 / 水墨武侠 / Art Deco / 像素艺术 / 赛博朋克 / 霓虹
- 情绪→整套参数查 `references/aesthetic-params.md`

## 七、逐项实现（补全收敛判据）
简单起步 → 每轮加一个画面要求 → 最复杂放最后 → 失败可回退。
- 停止：新增要素清晰出现，且前轮要素未退化/冲突
- 回退：用**上一版提示词**重新生成（不复用上一版画面结果）
