# 范例 · 实验室女工程师（角色一致性卡 + 正向 chaining 触发实例）

> 这是 /devflow-video 的 few-shot 范例之四，专门演示**前三个范例都没覆盖的一条正向路径**：
> 1. **贯穿主体为"角色"（需固定长相）→ 启用角色卡**（`references/character-card.md`），出 `<项目名>/character-prompt.md`：五要素长相锁死 + 正脸/侧脸/3-4 侧朝向。画面段**只写动作/朝向/光线，长相写"见角色卡"不重复**。
> 2. **chaining 正向入口**：角色卡 = 各镜首帧参考图的规范来源。本例目标模型**指定为"Kling（支持首尾帧垫图）"**，因此 chaining 从"未触发"变为"可触发"——这是 chaining + 角色卡首次有正向实例（mars 范例是 chaining 示意但未指定垫图模型）。
> 3. **物体/角色分流**：女工程师是**角色主体**走角色卡；她要操作的机器人是**物体主体**走 chaining 尾帧——同一项目两类主体各归其位。
>
> 注意：本范例**未做真实出片验证**，角色卡多朝向写法是通用扩散角色卡惯例（未实测），不代表 Kling 或其他模型上的最优解；出片回传后按步骤 7 回修。

## 需求

- 主题：一位女工程师在实验室巡视并操控一台机器人，5 个镜头
- 时长：**20 秒**，5 段（0~4s / 4~8s / 8~12s / 12~16s / 16~20s）
- 目标模型：**Kling（假设支持首尾帧垫图）**
- 风格：写实科幻，冷调
- 贯穿主体：**女工程师（角色，需固定长相）+ 实验室机器人（物体）**
- 对齐判定：主角（女工程师）明确、时长（20s）明确、风格/情绪（写实冷调）明确、场景 ≤2（实验室 + 机器人台）且已描述 → 四条门槛全满足，**已跳过 grilling**

## 角色卡（character-prompt.md，本例启用，Kling 支持垫图）

**五要素长相（全片锁死，画面段不复述）：**
1. 五官：东亚女性，圆脸，眉形平直，黑瞳
2. 发型发色：深棕色齐耳短发，发尾内扣
3. 服装：白色实验服，内搭深灰圆领衫，胸口挂工牌
4. 体型：中等偏瘦，约 165cm
5. 年龄/种族：30 岁，东亚

**多朝向立绘需求（画布/垫图消费）：** 正脸 + 侧脸 + 3/4 侧，中立站姿，平光中性背景。
**朝向选取（沿用 chaining 参考帧判据）：** 各镜按机位朝向选最接近的一张；后脑/大俯段不垫角色卡，退化回"文字写清同一女工程师+一致性约束"。

## 遗留风险

- **角色卡多朝向写法未出片验证**：正脸/侧脸/3-4 侧三朝向是扩散角色卡惯例，Kling 对角色卡垫图支持度未实测；若出片某朝向跳变，删该朝向回退"文字写清同角色+一致性约束"，来源标注走步骤 7 回写。
- **第 3/4 段机器人是物体主体走 chaining 尾帧，非角色卡**：机器人无固定"长相"一致性需求，垫上一段尾帧即可；若需要跨多段固定机器人外观，才给机器人单独出物体卡（本例未做，标注为可选扩展）。
- **Kling 是假设模型**：本例指定 Kling 仅为了演示 chaining 正向触发；实际以用户目标模型为准，`model-matrix.md` 未查证垫图支持时保持"未查证，保守启用"标注。
- 本范例**未经真实出片验证**，结构正确 ≠ Kling 实测最优。
