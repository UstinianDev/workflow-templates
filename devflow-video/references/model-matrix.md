# 各模型支持矩阵 + 高频措辞库（可选特化层，按需加载）

> 定位：本工作流通用、不锁模型。仅当**用户指定目标模型 且 查到可引用官方 prompting guide** 时才填入。无来源不捏造（核心理论"不捏造"原则）。

## 默认行为（未指定模型 / 无来源时）
- **负面提示词：不假设"不支持"，也不假设"支持"——标注"未知，按目标模型查询"**。已知的支持负面字段的模型（如 Runway、Kling）应按"支持"给出负面词表，不要一刀切去掉（去掉有效负面控制 = 主动降质）。
- 时间戳法保守启用（首尾帧垫图需目标模型支持才开，默认不开）
- 高频措辞取 `term-mapping.md` 右侧高频标准术语，不猜"某模型实测最优组合"

## 按目标模型填入项（有来源才填，逐条注明来源）
- 是否支持负面提示词（yes/no + 来源；支持则附该模型负面词表）
- 对时间戳法 / 首尾帧垫图的支持（支持/不支持 + 来源）
- 实测高频有效措辞组合（组合 + 来源链接）
- **单段时长上限 / 画幅 / 运动幅度规格**（模型实际约束 + 来源）

**填入方式**：用户指定模型后，`crw scrape` / `docs-cli scrape` 抓该模型官方 prompting guide；拿到可引用来源才写入。查不到保持本节为空、并在输出标注"模型特化未查证"。
