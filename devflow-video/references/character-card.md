# 角色一致性卡 character-card(角色主体多镜头,按需加载)

> 何时读:分镜 ≥2 段且"贯穿主体是**角色**(人/动物/固定长相物体,需跨镜头同一张脸/同一外观)"时。
> 物体主体(齿轮/建筑/车)不走本文件,走 `references/chaining.md`(尾帧垫图);本文件是 chaining 的**首帧参考图来源**规范。
> 来源声明:多朝向角色卡 = 扩散式文生图角色卡通用做法(一次出齐正脸/侧脸/3-4 侧作垫图锚点),**未标具体模型**;各模型对角色卡垫图支持度查 `references/model-matrix.md`,无来源则标"角色卡垫图支持未查证,按保守启用"。
> 诚实定位:本卡与 aesthetic-params 同级是**未出片验证的推测层**——多朝向写法合理但未实测,出片回传后按步骤 7 回修,不当硬规格担保。

## 核心机制
- **角色卡 = 一张跨镜头锁定的长相描述 + 多朝向立绘需求**,作为各画面段**首帧参考图**的规范来源。
- 目的:画布/垫图工作流先出角色立绘(正/侧/3-4 侧),再拿立绘当首帧参考图垫进各段——比"每段文字重新描述长相"一致性强(纯文本描述各段会被模型重新发明相似但不同的脸)。
- 与 chaining 的关系:`chaining.md` 管"上一镜**尾帧** → 下一镜**首帧**衔接";本文件管"**角色立绘 → 各镜首帧参考图**入料"。两者配合:物体主体走 chaining 尾帧,角色主体先出卡再垫。

## 角色卡五要素(长相锁死,全片不复述)
1. 五官/面部特征 2. 发型发色 3. 服装 4. 体型 5. 年龄/种族
- 这五项写在 `character-prompt.md` 里**一次锁定**,段级画面提示词**只写"该角色此刻的动作/朝向/光线"**,长相一律引用"见角色卡",不重复描述(避免过度指定,呼应 4.4)。

## 多朝向立绘要求(画布可消费)
- 一张角色卡出齐**正脸 + 侧脸 + 3/4 侧**三种朝向,中立姿态、平光中性背景。
- 为何要三朝向:各段机位朝向不同(正拍/侧拍),垫图朝向与机位差太远会跳变——三朝向覆盖常见机位,垫图时按"该段朝向选最接近的一张"(沿用 chaining.md 参考帧选取判据)。
- 朝向差太大的段(如某段要后脑勺):角色卡不提供后脑参考,该段退化回"文字写清同角色+一致性约束",并标遗留风险。

## 启用边界(防滥用,写死)
- **仅角色主体启用**(人/动物/需固定外观的角色)。物体主体(齿轮/建筑/车)不启用,走 chaining 尾帧。
- 单镜头 / 无贯穿角色 → 不启用。
- 判定:看步骤 1 对齐时的"主角"是否为需跨段同一长相的角色。

## 失败回退
接不上 / 垫图跳变:回退 `core-rules` 第七节——用**上一版提示词**重生成,不用上一版画面结果(避免误差累积)。

## 未查模型支持时
目标模型未指定或 `model-matrix` 未查证角色卡垫图支持 → 保守启用,遗留风险标"角色卡垫图支持未查证,若目标模型不支持 image-to-video 角色垫图,主体一致性退化回纯文本(长相描述+一致性约束)"。

## 输出
角色卡落盘为 `<项目名>/character-prompt.md`(条件生成,仅启用时),frontmatter:`project / module: character-prompt / generated_at / target_model / 角色名 / 朝向清单`。
